CSPC SpaceHub - Privacy and Calendar Update

Changes:
1. Student/faculty dashboard shows only the logged-in user's own reservations and status counts.
2. Admin dashboard continues to show/monitor reservation requests across all users.
3. Calendar is now a shared facility-availability view for authenticated users:
   - Shows Pending reservations and Booked (Approved) reservations for all facilities.
   - Shows facility name, date, and start/end time.
   - Does NOT show requester/reserver name, school ID, email, reference number, purpose, or other private request details to non-admin users.
   - A non-admin user can open only their own reservation from the calendar.
   - Other users' calendar entries are non-clickable.
   - Admins can open reservation entries for monitoring/approval.
4. Admins do not see the Make Reservation button on the calendar.
5. Approved reservations are displayed as "Booked" on the calendar.
